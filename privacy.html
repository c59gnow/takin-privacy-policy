Politique de Confidentialité - Taquin

Cette politique décrit comment l'application mobile Taquin traite vos données. En utilisant l'application, vous acceptez ces pratiques.

Données collectées

  • Données techniques : identifiants publicitaires (Google/Apple), informations de l'appareil (modèle, version OS), journaux d'erreurs.
  • Progression de jeu : niveaux déverrouillés, scores (temps et coups) stockés localement; si vous activez les classements en ligne, ces scores sont envoyés avec votre identifiant de connexion Google.
  • Annonces : Google AdMob peut collecter des données d'usage publicitaire selon ses propres règles. Consultez la politique Google : Google Privacy.

Usage des données

  • Fournir et améliorer les fonctionnalités du jeu (scores, déblocages).
  • Afficher des publicités via AdMob (bannières et récompenses).
  • Classements en ligne si vous vous connectez (Firebase/Google Play Services).

Partage des données

  • Publicités : données partagées avec Google AdMob pour la diffusion et la personnalisation (selon vos réglages publicitaires).
  • Analytique/erreurs : les journaux peuvent être envoyés aux services tiers intégrés (ex. Firebase) uniquement pour diagnostic.
  • Nous ne vendons ni ne louons vos données.

Contrôles et choix

  • Vous pouvez réinitialiser votre identifiant publicitaire dans les réglages de votre appareil.
  • Vous pouvez jouer sans connexion pour limiter les envois de données en ligne (les publicités peuvent nécessiter Internet).
  • Supprimez l'application pour effacer les données locales (scores/progression).

Sécurité

Les données transitent via des connexions chiffrées vers nos prestataires (Google/Firebase/AdMob). Nous appliquons les bonnes pratiques recommandées pour protéger vos informations.
